# QQ 群聊增强

用于增强 QQ机器人的群聊能力，目前主要实现**关键词唤醒**、**JEV 语义唤醒**和**@优化**

## 🌟 功能亮点

* **关键词唤醒**：Astrbot 自带的前缀唤醒和@唤醒会移除唤醒词和@，在一些情况下会使机器人收到的上下文变得不自然，本插件实现了唤醒词和@的保留。
* **JEV 语义唤醒**：本插件目前的重点功能，让机器人结合上下文，判断一句话是不是在对自己说，而不必每次输入关键词或@唤醒。

## 🔀 工作流程

> 以下数值皆可在配置中进行调整。

**1. 触发唤醒条件** 满足以下任一条件即可唤醒机器人：

- 引用机器人消息
- @机器人
- 触发本插件提供的关键词
- 其他插件唤醒

**2. 清醒状态（Active State）**

- **持续时间**：唤醒后进入 **180秒** 的清醒状态。
- **状态刷新**：在机器人的回复成功发送后会刷新清醒状态窗口。
- **处理逻辑**：
  - 接收到的群消息进入 **3秒防抖窗口（最多等待 6 秒）**。
  - 窗口超时后，将当前消息连同**最近30条**历史记录发送给 **JEV模型**。
  - JEV 逐条判断是否是对机器人说的，若是则通过内部事件正式唤醒。

**3. 非清醒状态（Idle State）**

- **消息判断逻辑**：
  - 检查该消息是否距离机器人最后一条发出的消息在 **5条以内**。
  - **是**：进入 **3秒防抖窗口**，随后送入 JEV 进行唤醒判断。
  - **否**：忽略或不进行处理（视具体配置而定）。
- **作用范围**：
  * 超出清醒窗口的消息。
  * 命令产生的机器人回复。

**4. 流程图**

```python
群消息
  ├─ 正常流转 → AstrBot / 其它插件 → 聊天模型请求与回复
  │                                      │
  │                              观察实际输入覆盖的消息
  │                                      ↓
  └─ 本插件观察 → 检查清醒状态或消息距离 → 待判窗口 / 判断批次 ← 清理已覆盖消息
                                         ↓
                         3 秒防抖 / 6 秒最长聚合 + 历史缓存
                               			 ↓
                               			Jev
                                         ↓ 判断通过
                                   内部请求回复事件
                                      	 ↓
                                   独立模型回复任务

退出待判的消息 → 转入历史缓存，保留最近 n 条
显式唤醒跳过 Jev；本轮模型回复成功发送后进入或刷新清醒。
```

* **QQ 组件语义化**：Astrbot 原生不支持处理QQ表情、戳一戳、卡片（音乐、定位、名片等）、红包、猜拳、骰子等组件和事件消息，可以通过 [QQ 能力增强]([QQ 能力增强 - AstrBot Cloud](https://cloud.astrbot.app/plugin/rytte/astrbot_plugin_qq_enhance)) 插件执行语义化处理，有助于 JEV 理解上下文。
* 更多 JEV 配置、判断流程、清醒规则及实现细节见 [Jev 语义唤醒说明](JEV.md)。

## 🚀 快速上手

需要 **AstrBot `>=4.27.4,<5`**、Python 3.12+，以及 `aiocqhttp` / NapCat OneBot v11。语义唤醒使用 AstrBot **本地 Agent 执行器**。当前回归测试基于 AstrBot **4.27.4**，新版本的内部接口仍需验证。

1. 将插件目录放入 `data/plugins/astrbot_plugin_qq_group_enhance`，在 AstrBot 中加载插件。
2. 打开插件配置，在 **Jev 语义唤醒**中填写 API Key。接口地址、模型版本及参数说明见 [Jev 接入与配置](JEV.md#接入与配置)。
3. 保存配置并重载插件。先 @机器人聊一句，再发送不带 @ 的追问，观察它是否接话。

## ⚙️ Astrbot 配置

* 开启 **群聊消息记录注入上下文**，不需要开启“持久化群聊消息记录”。
* 群内共享对话时，建议关闭 **会话隔离**。
* 默认 AI 聊天的唤醒前缀留空。使用本插件的关键词时，从 AstrBot 自带唤醒前缀中移除同名词，避免正文提前被删改。

## 🧠 @与群聊上下文

**@机器人时模型能看到什么？** QQ 适配器通常会从正文中移除机器人自己的第一个 @。开启“保留机器人 @昵称”后，本插件会在模型可见正文前补回 `@机器人昵称`，保留原始消息链。只有一个机器人 @时同样直接进入普通模型回复，不进入 AstrBot 的“只 @ 机器人触发等待”流程；关闭后恢复 AstrBot 原有处理。

开启 AstrBot 的“群聊消息记录注入上下文”时，插件会为核心漏记的纯 @ 消息补齐原生记录，使“先发一句话、再单独 @机器人”也能带上前面的群聊内容。记录在回复防抖前完成，已有记录不会重复添加，无需修改 AstrBot 源码。
